{%- comment -%} Top-level version switcher: the docs site's release-version picker. Rendered site-wide by header_custom.html, in the page header. "latest" (the default) is the live main tree at /; every other version is a snapshot under //, created at release time by scripts/version-snapshot.sh and listed in _data/versions.yml. Selecting a version swaps the URL prefix and keeps the rest of the path, so you land on the same page (or that version's index) in the other line. The active entry is marked from page.version_snapshot or from the current URL prefix. The dropdown is a plain
element: keyboard and screen-reader usable without JavaScript; assets/js/versions.js only adds close-on-outside-click. {%- endcomment -%} {%- assign parts = page.url | split: "/" -%} {%- assign prefix = parts[1] -%} {%- assign page_version = "" -%} {%- if page.version_snapshot -%} {%- assign page_version = page.version_snapshot | append: "" -%} {%- else -%} {%- assign parts = page.url | split: "/" -%} {%- assign prefix = parts[1] -%} {%- for v in site.data.versions.versions -%} {%- assign vname = v.version | append: "" -%} {%- if vname != "latest" and vname == prefix -%}{%- assign page_version = vname -%}{%- endif -%} {%- endfor -%} {%- if page_version == "" -%}{%- assign page_version = "latest" -%}{%- endif -%} {%- endif -%}
