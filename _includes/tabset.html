{%- comment -%} Generic accessible tab set, CSS-only (radio buttons), works without JavaScript. Called by tabs.html and code-tabs.html; use those rather than calling this directly. Markup: all radios first, then all labels (they float left into the visible tab bar), then all panels. The checked radio reveals its panel via the float-queue rules in assets/css/tabs.css (radio N pairs with panel N by :nth-of-type position). Radio N is followed in the DOM by label N, so Tab order follows the bar left-to-right, and the focused radio outlines its own label. Params: id unique id prefix on the page, kebab-case (required) labels space-separated list of tab labels, rendered in this order p1 .. p5 panel content (markdown), aligned with `labels`. A missing or empty panel renders `fallback` instead. fallback HTML shown for a missing panel {%- endcomment -%} {%- assign labels = include.labels | split: " " -%}
