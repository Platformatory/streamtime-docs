# Reference

Generated references for each interface. Task pages elsewhere in these
docs show each task in every interface (UI, API, CLI, MCP and Terraform);
the references list everything an interface offers.

| Interface | Reference |
|---|---|
| Terraform | [Terraform provider]({{ site.baseurl }}/terraform/): every resource and data source, with its arguments and import syntax |
| API | The OpenAPI document your installation serves at `/api/schema/public/` (no sign-in needed; `streamtime openapi` fetches it), and the generated SDKs: [Python](https://pypi.org/project/streamtime-sdk/) and [TypeScript](https://www.npmjs.com/package/@streamtime.ai/sdk) |
| CLI | `streamtime --help`, and `--help` on every command |
| MCP | The tool list your MCP client shows once connected |

How to connect each interface: [Interfaces]({{ site.baseurl }}/getting-started/interfaces/).
