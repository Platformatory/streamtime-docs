Getting Streamtime installed, configured, and running your first
workload. Work down the list:

1. **[Installation](/getting-started/installation/)** — the single
   image, Docker Compose, or the Helm chart; interactive or headless.
2. **[Configuration](/getting-started/configuration/)** — domains and
   certificates, identity providers, and the cloud accounts your
   fleets will use.
3. **[User Management](/getting-started/user-management/)** —
   organizations, users, invites and roles.
4. **[Package Management](/getting-started/package-management/)** —
   the software packages and versions Streamtime deploys, the package
   catalog, and how upgrades roll out.

Then continue with [Fleet Management](/fleet-management/) to bootstrap
a fleet and [Workloads](/workloads/) to run something on it.
