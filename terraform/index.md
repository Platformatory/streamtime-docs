# Terraform provider

The Streamtime provider lets you manage Streamtime resources as code. For
installation and sign-in, see [Getting started with Terraform]({{ '/getting-started/terraform/' | relative_url }}).

Each page below documents one resource: its settings, an example and how to
import an existing object.
